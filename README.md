# LoanQuote

Cotizador de préstamos y plan de amortización desarrollado con HTML, CSS, JavaScript y jQuery.

## Características
- Cálculo dinámico de amortización (Cuota fija y Capital fijo)
- Soporte para pagos extraordinarios dinámicos
- Resumen financiero en tiempo real
- Generación de cotización detallada con fecha y hora exacta
- Interfaz responsiva con Bootstrap 5
